# Linked follow-up PRs

A PR is linked only when it mentions the original PR on the original PR's thread. Treat it as a reference proposal:

1. Mark it ready when authorized so reviewer bots run; an authorization failure blocks only if it prevents inspection or validation.
2. Validate its diff and reviews claim by claim. Put valid changes on the original head, preserving attribution for reused substantive code.
3. Before closing it, prove every valid concern is covered or defensibly dismissed on the original head, and post that evidence. Close it when authorized and confirm; otherwise leave it open and report why.
